# Face Hugger

Native macOS SwiftUI upload utility for Hugging Face. Finder-like three-column window: translucent 220 px sidebar, central upload queue, 300 px inspector. Light neutral system surfaces, SF Pro system typography, 13 px controls, 24 px page title. Yellow brand #FFD24B; darker amber #B76B00 for accessible small accent text; folder blue #3699E3; ink #29313B. Native list rows, restrained separators, no dashboard cards, no web marketing hero, no decorative gradients. Standard macOS toolbar with traffic lights, sidebar toggle, New Upload, inspector toggle. Sidebar: Uploads, History, Repositories grouped by account, connection account at bottom. Upload row shows folder, destination, status, determinate progress only when known. Inspector shows source, destination, stages Prepare / Upload / Commit and expandable logs. Personality comes only from a glossy smiling Hugging Face-style yellow emoji wrapped by a tan Alien-style facehugger with segmented fingers and curved tail, non-scary, used in app icon and empty state. Use system success green and error red plus text. Native materials, SF symbols, 8/12/16/24 spacing. Design desktop 1200x780. Realistic file names and upload activity. No charts or fake business metrics.
